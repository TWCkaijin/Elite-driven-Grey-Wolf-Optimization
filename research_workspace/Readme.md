# **工作區説明**

## 使用方法

- 每個研究都應創建一個新資料夾。
- 資料夾名稱應為研究的標題。
- 每個資料夾應包含以下 `readme.md` 以簡要描述研究內容。
- 請隨時更新此 `readme.md` 文件（workspace主readme），包含研究標題和簡短描述。

## 範例資料夾結構

``` raw
research_workspace/
├── （研究標題）/
│   ├── readme.md（required） - 研究概述
│   ├── [references] - 論文或參考文獻
│   ├── data（optional） - 數據
│   └── scripts/（optional） - 關聯程式碼
│    
├── Readme.md (此文件) - 工作區注意事項及文件概述
```
